# GameUI Studio 使用指南

## 配置与运行

复制根目录的 `.env.example` 为 `.env.local`，按本机环境修改：

| 配置项 | 用途 |
| --- | --- |
| `MAGPIE_BIN` | Magpie CLI 命令或可执行文件绝对路径，默认 `magpie` |
| `MAGPIE_GATEWAY` | 模型网关，默认 `http://127.0.0.1:3425/v1` |
| `MAGPIE_KEY` | 网关要求的密钥；示例值只适用于本地网关 |
| `MAGPIE_VISION_MODEL` | 视觉分析和布局规划模型，需使用网关实际支持的模型名 |
| `GAMEUI_DATA` | 工作数据目录，默认 `.data` |

图像生成通过 `magpie mcp image` 调用 Magpie 配置的图像模型。以上配置只在服务端读取，不要将密钥放入会暴露给浏览器的 `VITE_*` 变量。修改配置后重启开发服务。直接运行模型探测脚本时，需在 shell 中设置环境变量。

启动命令见根目录 README。工具面向本机使用，不提供公网账户鉴权或多人数据隔离。静态构建不包含服务端 API，不能仅上传 `dist` 就获得完整工作台。

## 项目与布局

在首页创建或打开项目，设置界面尺寸与画风。项目可包含多个界面，支持重命名、复制和删除。界面按布局、生成和素材三个阶段组织，已有任务和结果可在刷新后恢复。本机复制不等同跨机器可携带包。

使用模板、参考图分析或手工添加节点建立线稿。布局编辑器支持父子树折叠、节点预设、容器归属、分组移动缩放、对齐、撤销和重做。无限画布支持围绕鼠标位置缩放和拖动平移。确认布局后保存线稿，再进入生成阶段。

## 效果图与版本

选择画风，结合布局和提示词生成效果图；通过微调创建后续版本，按需修改名称、备注并对比整图。

任务通知显示生成状态。中断后可继续等待已有结果，或明确发起重新生成；重新生成属于新的模型调用。项目生成和微调会检查结果比例，不会静默拉伸不符合要求的图像。

## 素材编辑

资源编辑器提供原图与素材图集双画布，可独立缩放、拖动和取色。支持检测素材矩形、手工框选、调整区域、蒙版擦除与恢复，以及逐项审核。

简单背景可使用色键提取；局部分割需要准备本地 SAM2 运行时。蒙版修整用于保留或去除已有像素，AI 补图用于重绘遮挡区域。从首页进入独立切图工具，可直接上传截图并管理切图任务。

### 本地分割运行时

分割服务按以下位置查找运行时，不会自动下载源码或权重：

| 路径 | 内容 |
| --- | --- |
| `.venv-seg/Scripts/python.exe` | Python 运行环境 |
| `.data/segmentation/sam2/source/` | SAM2 源码 |
| `.data/segmentation/sam2/site/` | 隔离的 Python 依赖 |
| `.data/segmentation/sam2/sam2.1_hiera_small.pt` | SAM 2.1 small 权重 |

配置为 `configs/sam2.1/sam2.1_hiera_s.yaml`。需要自行按模型项目说明准备依赖与权重，当前服务路径面向 Windows。缺少运行时会返回错误，已有素材仍可检查和导出。

### AI 拆图

在项目资源编辑器点击“AI 拆图”，输入拆分要求。模型将当前效果图重绘为透明组件表，前端按 alpha 连通区域裁切，将组件加入当前素材任务。

拆图不会新建界面版本，也不经过视觉检测或 SAM2。组件像素来自模型生成的组件表，可能与原图不同。透明背景和组件分离程度取决于模型输出，细小和半透明边缘需要人工检查。

## 独立画图与画风库

独立画图支持提示词、最多 5 张参考图和分辨率请求。结果保留原图，并显示实际尺寸；模型不一定严格遵守请求尺寸。

画风库支持手工创建、AI 分析、编辑、重命名、复制和删除。AI 创建画风时分析名称与提示词，直接保存上传的 1–12 张原始参考图，不额外生成画风预览图。

## 资源导出

审核素材后导出透明 PNG、素材清单和原图坐标。命名采用 `T_UI_<模块>_<对象>[_<状态>].png`，重复名称会添加数字后缀。

素材图集支持打包预览与导出。整页导出可选择当前界面或全部界面，并按原始尺寸或预设尺寸输出 ZIP；调整尺寸时保持比例，以透明区域补足。

Unity 导出包包含 `GameUiSliceImporter.cs`。将 PNG 放入 `Assets/Art/Textures/UI/<模块>/`，将脚本放入 `Assets/Scripts/Editor/`，在 Unity 执行 `Tools/GameUI/Apply UI Import Settings` 设置 Sprite 导入参数。九宫格建议需要人工确认。

## 数据与使用边界

- 工作记录、上传图片和生成结果保存在 `GAMEUI_DATA`。备份时包含整个数据目录，避免运行中覆盖正在写入的数据。
- 外部模型调用会发送提示词及所选参考图，并可能产生费用。
- 复杂背景、透明 HUD、空心控件和遮挡内容需要人工复核；自动处理不能保证恢复原始分层。
- 模型权重和素材授权按其实际来源确认，项目许可证不替代第三方授权。
